# 🛍️ Customer Segmentation Using Machine Learning

## 📌 Project Overview

Customer Segmentation is an unsupervised machine learning project that groups customers into different segments based on their annual income and spending behavior.

This project uses **K-Means Clustering** to identify meaningful customer groups, helping businesses understand customer behavior, improve marketing strategies, and make data-driven decisions.

## 🎯 Objectives

- Analyze customer purchasing behavior.
- Identify customer groups using clustering.
- Apply K-Means clustering algorithm.
- Determine the optimal number of clusters using the Elbow Method.
- Visualize customer segments.
- Generate business insights and marketing strategies.

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## 🧠 Machine Learning Algorithm

**K-Means Clustering**

K-Means is an unsupervised learning algorithm that divides data points into K clusters based on similarities between their features.

### Features Used
- Annual Income (k$)
- Spending Score (1–100)

## 📊 Project Workflow

1. Import required libraries

4. Data visualization
5. Feature selection

7. Train the K-Means model
8. Visualize customer segments
9. Analyze clusters
10. Generate business insights

## 📈 Results

The model identifies customer segments based on income and spending behavior.

These segments can help businesses identify:
- High-income, high-spending customers
- High-income, low-spending customers
- Low-income, high-spending customers
- Low-income, low-spending customers
- Average customers
